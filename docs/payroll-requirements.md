# 급여·인사 운영 기준

기준일: 2026-09-25 · 질문 426번 및 9월 25일 일 그레이드 정정 반영. 예시 금액은 실제 운영 설정값이 아니다. 구현 상태는 [구현 현황](PAYROLL_IMPLEMENTATION.md)을 확인한다.

이후 미정 운영 항목은 사용자 위임에 따라 기존 확정 기준에 맞는 추천안을 선택한다. 기존 답변을 일괄 변경하지 않으며, 문서 검토·제도 결정을 기다리는 항목은 아래 보류 목록을 유지한다.

추가 결정의 출처와 통합 이력: [309~426번 결정 기록](payroll-decisions-309-426.md).


## 일반 직원 시급·그레이드

| ID | 항목 | 확정 기준 | 예시·참고 |
| --- | --- | --- | --- |
| G-001 | 실적 귀속 월 | 한 달 정상 실적 총건수로 해당 월 근무 시급을 결정한다. 다음 달 15일에 변수를 처리한 해당 월 급여를 지급한다. | 9월 실적에 따른 시급을 9월 근무에 적용하고 10월 15일 지급. 후속 달 근무의 시급을 정하는 방식이 아님. |
| G-002 | 상품별 시급표 | 보험·건강보조식품·화장품 등 상품 담당 부서별 시급표를 별도로 적용한다. | 보험 시급표와 화장품 시급표 분리. |
| G-003 | 보험 일반·실버 | 보험 일반·실버 실적은 합산하고 보험 시급표 하나를 적용한다. |  |
| G-004 | 직원 기본시급 | 직원별 기본시급을 설정한다. 실적이 없거나 최저 구간 미달이면 기본시급을 적용한다. | 실제 기본시급 금액은 직원별 설정값. |
| G-005 | 기본시급 보장 | 달성 그레이드 시급과 직원 기본시급 중 높은 금액을 적용한다. | 기본 12,000원, 그레이드 11,000원이라면 12,000원 적용. 금액은 예시. |
| G-006 | 기본시급 변경 | 변경 적용일부터 새 기본시급을 적용하고 전후 기간을 나누어 계산한다. | 1~15일 기존, 16일부터 신규 기본시급. |
| G-007 | A/S 반영 | 급여 확정 전 관리자 차감으로 정상 실적이 줄면 시급 구간도 다시 계산한다. | 확정 후 변동은 해당 급여 및 이후 급여에 반영하지 않는 원칙. 실적 이전의 별도 예외는 실적 시트 참조. |
| G-008 | 기본급 계산 | 부서·시급 적용 기간별 인정시간에 해당 시급을 곱한 금액을 합산한다. | 기본시급 보장 및 주휴 포함 시급 구분 기준을 함께 적용. |
| G-009 | 기본급 원 미만 | 월 기본급의 계산액을 모두 합산한 뒤 원 미만을 한 번 버린다. | 500,000.6원 + 500,000.6원은 1,000,001원. 기간별로 먼저 버리지 않음. |
| G-010 | 변경 단위 | 부서는 날짜 단위로 변경한다. 하루에는 한 부서만 근무한다. | 여러 팀 겸임 팀장은 별도 운영 기준 적용. |
| G-011 | 시급 적용 시간 | 각 부서에서 인정된 근무시간에 해당 부서의 시급을 적용한다. |  |
| G-012 | 주·월 비율 | 해당 부서 인정시간을 직원의 해당 주·월 전체 인정시간으로 나누어 비율을 계산한다. | 부서 40시간 ÷ 전체 100시간 = 40%. 유급으로 인정한 휴가·지각 시간 포함. |
| G-013 | 기준 건수 조정 | 주·월 그레이드의 기준 건수는 부서별 인정시간 비율로 조정한다. | 기준 100건 × 부서 비율 40% = 40건. |
| G-014 | 달성수당 조정 | 주·월 달성수당 금액도 해당 부서 인정시간 비율로 조정한다. | 월 구간 수당 20만 원 × 40% = 8만 원. |
| G-015 | 지급 항목 | 일 그레이드는 TM 상담원에게만 지급하는 별도 달성수당이다. 팀장·관리직·관리자는 제외한다. 한국 시간 기준 매일 0건·0원부터 새로 집계하며 이전 날짜의 실적·금액은 이월하지 않는다. 과거 지급 기록은 별도 보존한다. | 2026-09-25 사용자 정정. 기존 급여 합산·기지급 차감 기준을 대체. |
| G-016 | 달성 구간 | 가장 높은 달성 구간의 수당만 지급한다. 낮은 구간 수당을 누적하지 않는다. | 예시 최고 달성 구간 1만 원이면 총 1만 원. |
| G-017 | 현금 지급 | 최고관리자·급여 관리자가 지급 시점에 계산한 일수당 전액을 현금 지급한 뒤 지급 완료를 표시한다. 일수당 일부 지급 기록은 지원하지 않는다. | Q-403: 지급 시점의 전액 지급만 기록. Q-404: 실제 지급일을 선택한다. |
| G-018 | 미지급액 | 미지급 일 달성수당도 월 급여로 합산하지 않는다. 관리자 일 그레이드 메뉴에서 별도 지급·내역을 관리한다. | 2026-09-25 사용자 정정. 기존 급여 합산·기지급 차감 기준을 대체. |
| G-019 | 일부 시간 근무 | 일부 시간만 근무해도 일 기준 건수는 유지한다. 달성하면 해당 구간 수당 전액을 인정한다. | 2시간 근무라도 기준 10건을 달성하면 해당 일수당 전액. |
| G-020 | A/S와 기지급액 | A/S로 당일 조건에 미달해도 이미 지급한 일 그레이드 지급 기록은 유지한다. 월 급여 확정 여부와 별개로 관리한다. | 2026-09-25 사용자 정정. 기존 급여 합산·기지급 차감 기준을 대체. |
| G-021 | A/S와 미지급액 | 아직 지급하지 않은 일수당은 A/S 차감 후 정상 실적으로 다시 계산한다. | 미지급 일수당도 무조건 보장하던 해석은 적용하지 않음. |
| G-022 | 정상 전환 증가분 | 정상 전환에 따른 과거 일 그레이드 증가분은 별도 일 그레이드 내역에서 관리하며 월 급여나 주휴수당에 합산하지 않는다. | 2026-09-25 사용자 정정. 기존 급여 합산·기지급 차감 기준을 대체. |
| G-023 | 집계 기간 | 월요일부터 금요일까지를 주 실적 집계 기간으로 사용한다. | 주휴수당의 월~일과 별개. |
| G-024 | 지급 방식 | 해당 주 최고 달성 구간 수당만 산정하고 월 급여일에 별도 항목으로 합산 지급한다. | 예시 최고 구간 5만 원이면 해당 주 5만 원. |
| G-025 | 월을 걸치는 주 | 주가 끝나는 달의 급여에 해당 주 달성수당 전액을 포함한다. | 9월 말~10월 초 주라면 주 종료일이 속한 10월 급여에 반영. 월별 근무일수로 나누던 이전 선택 폐지. |
| G-026 | 지급 방식 | 월 실적으로 시급을 결정하면서 월 최고 달성 구간 수당도 별도로 추가 지급한다. | 최고 달성 월 구간 수당이 20만 원이면 해당 수당 20만 원. |
| G-027 | 대상과 시작점 | 월 그레이드에만 건당 추가수당을 적용한다. 최상위 구간 기준 건수를 초과한 건수만 인정한다. | 최상위 100건, 실적 105건이면 초과 5건. |
| G-028 | 부서 이동 조정 | 최상위 기준 건수와 초과 건당 지급액 모두 부서 인정시간 비율로 조정한다. | 최상위 100건·건당 1,000원·비율 40%이면 40건 초과부터 건당 400원. |
| G-029 | 근무일수 비례 폐지 | 공휴일·중도 입퇴사·표 변경 기간 등을 이유로 한 모든 그레이드의 근무일수 비례조정을 하지 않는다. 실제 실적으로 계산한다. | 월 중 10일만 근무해도 일수 50%를 별도로 곱하지 않음. 부서 인정시간 비율은 유지. 관리직 월급의 달력 일수 조정과 구별. |
| G-030 | 병가·결근 | 병가가 있어도 주·월 기준 건수와 달성수당을 근무일수로 줄이지 않는다. 무급 시간은 기본급 인정시간에 반영한다. | 부서·직책 인정시간 비율은 별도 적용. |
| G-031 | 실적 기준 반올림 | 비례 조정된 기준 건수의 소수점은 반올림한다. | 12.4건은 12건, 12.6건은 13건. |
| G-032 | 양수 기준 최소값 | 원래 1건 이상인 주·월 달성 기준은 비례 조정 후 반올림 결과가 0건이어도 최소 1건을 적용한다. | 1건 × 10%는 최종 1건. |
| G-033 | 수당 반올림 | 각 수당의 최종 금액을 원 단위 반올림한 후 합산한다. 중간 계산의 단가를 먼저 반올림하지 않는다. | 0.5원 이상 올림, 미만 버림. |
| G-034 | 인정시간 0 | 주·월 전체 급여 인정시간이 0시간이어도 정상 실적이 있으면 부서별 정상 실적으로 주·월 달성수당과 월 추가수당을 계산한다. | 근무시간 비율 조정 없이 계산. 0시간이라는 이유로 수당을 일괄 0원 처리하지 않음. |
| G-035 | 부서 공통 | 같은 부서의 모든 팀이 동일한 일·주·월 그레이드표를 사용한다. | 그레이드표 등록·수정 권한은 최고관리자·급여 관리자. |
| G-036 | 적용 시작일 | 일·주·월 표마다 적용 시작일을 각각 지정한다. |  |
| G-037 | 과거 날짜 적용 | 과거 날짜 적용을 허용하되 해당 기간의 미확정 급여에만 소급 적용한다. | 확정된 급여를 표 수정만으로 변경하지 않음. |
| G-038 | 주·월 표 변경 | 주중·월중 변경 시 적용일 전후로 나눈다. 각 표 적용 기간 안의 실적만으로 등급을 결정한다. | 기간의 예정 근무일수 비율은 곱하지 않음. |
| G-039 | 표 변경 시 부서 비율 | 부서 인정시간 비율은 각 표의 적용 기간 안에서 계산한다. | 월 전체 비율 하나를 두 표에 공통 적용하지 않음. |
| G-040 | 기간별 수당 합산 | 표 변경 전후 기간에서 각각 달성한 주·월 수당을 합산한다. | 월 10만 원 + 20만 원 = 30만 원. |
| G-041 | 일 표 당일 변경 | 근무 도중 변경한 일 표는 당일 전체 실적에 새 표를 적용한다. 기지급액은 유지하고 차액은 일 그레이드 별도 내역으로 관리하며 급여에 합산하지 않는다. | 2026-09-25 사용자 정정. 기존 급여 합산·기지급 차감 기준을 대체. |
| G-042 | 표가 없는 경우 | 월 시급표가 없으면 직원 기본시급을 적용한다. 없는 수당표의 수당은 0원으로 처리한다. | 표 부재만으로 급여 확정을 막지 않음. |
| G-043 | 수치 관리 | 실제 구간 건수·시급·수당·건당 추가액은 설정값으로 관리한다. GitHub의 일·주·월 표는 참고자료로 사용한다. | 현재 대화의 예시 금액을 실제 확정된 표 값으로 고정하지 않음. |
| G-044 | 급여 방식 적용일 | 직책 변경 적용일부터 새 급여 체계를 적용하고, 전후 근무시간을 나누어 계산한다. | 일반 직원·팀장·관리직의 체계 분리. |
| G-045 | 일반직 실적 범위 | 일반 직원 주·월 그레이드는 해당 주·월 전체 본인 실적을 사용한다. 직책 변경 뒤 본인 실적도 포함한다. | 일반직 기간 30건 + 팀장 기간 40건 = 월 등급 판단 70건. 그 결과는 일반 직원 기간의 급여에만 적용. |
| G-046 | 일반직 수당 비율 | 주·월 달성수당과 월 추가수당에 일반 직원 인정시간 ÷ 해당 주·월 전체 인정시간을 곱한다. | 기준 건수에는 이 직책 비율을 추가로 곱하지 않고 기존 부서 조정만 유지. |
| G-047 | 표 변경과 동시 발생 | 표 적용 기간을 먼저 나누고 각 기간 안의 본인 실적을 직책 구분 없이 합산한다. 일반직 인정시간 비율도 각 표 적용 기간 안에서 계산한다. | 표 기간을 넘어 전체 월 실적을 중복 사용하는 방식 아님. |
| G-048 | 임의 추가 항목 | 일반 직원·팀장에게 임의의 별도 수당 입력 기능은 제공하지 않는다. 정한 그레이드·팀장 실적수당을 적용한다. | 수동 보정 및 별도 계산하기로 한 주휴·미사용 연차 항목은 각각의 규칙으로 관리. |
| G-049 | 직원 그레이드표 | 일반 직원은 본인의 현재 소속 부서 그레이드표만 조회한다. |  |
| G-050 | 표 기간 0시간 | 주·월 전체 인정시간은 있지만 특정 표 적용 기간의 인정시간이 0이면 해당 기간 주·월 달성수당과 월 추가수당은 0원이다. 전체 주·월 인정시간이 0인 G-034 예외와 구분한다. | 2026-09-24 추가 답변 반영 |
| Q-403 | 현금 일수당 전액 | 일수당은 지급 시점 계산된 전액을 현금으로 지급한 뒤 지급 완료로 기록한다. 일부 지급 기록은 지원하지 않는다. | 질문 403 사용자 답변 |

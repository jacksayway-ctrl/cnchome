# 원본 월 표 표시

2026-09-26 사용자가 제공한 8열 6행 표를 구간·금액·예상실적·예상지급액 그대로 보험 관리자·직원 화면에 표시한다. 100건 이상 추가 건당 10,000원 문구만 제거하고 취소건 제외 및 재콜 0.5건 문구는 유지한다.

원본의 구간과 예시가 불일치하므로 임의로 계산 규칙을 정하지 않는다. 원본 표는 정적 참고표이며 자동 계산과 미연결임을 화면에 표시하고 보험 월 계산 미리보기를 숨긴다. 기존 저장 정책과 실제 급여 엔진은 변경하지 않는다. 일·주 설정은 유지한다.

## 건수 구간 변경

후속 요청에 따라 100건 이하 / 101~110건 / 111~120건 / 121~130건 / 131~140건 / 141건 이상으로 표시한다. 실적수당은 각각 100·110·120·130·140건 초과분으로 표시하고 예상실적은 105·115·125·135·145건으로 맞춘다. 기존 시급·수당·예상지급액은 유지한다. 자동 급여 계산 연결은 이번 변경 범위에 포함하지 않는다.

## 시급 인상

표의 시급을 14,000→15,000원, 15,000→16,000원, 16,000→17,000원으로 각각 1,000원 인상했다. 위촉수수료 기본 표시도 동일하게 변경했다. 132시간 기준 예상지급액은 각 행 132,000원 증가하여 1,980,000 / 2,005,000 / 2,187,000 / 2,237,000 / 2,362,000 / 2,594,000원이다. 목표달성수당과 건당 실적수당은 유지한다.

## 기본 열 삭제

사용자 요청으로 기본 열과 각 행의 7 값을 제거했다. 위촉수수료의 기본 시급 표시 및 나머지 건수·금액은 유지한다.

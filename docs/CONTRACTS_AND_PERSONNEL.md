# 근로계약 · 인사기록 · 명세서 운영

2026-09-29 반영. 고용노동부 2025년 표준근로계약서와 임금명세서 안내의 항목을 참고한 회사용 양식이다. 실제 조건 입력과 당사자의 유효한 합의가 필요하며, 화면의 확인 버튼은 서명을 대신하지 않는다.

## 메뉴와 처리

- 관리자 → 인사·출결 → 근로계약: 사업장 기본 서식 저장 → 직원 초안 작성 → 실제 근로일별 시간·임금·기간 확인 → 발행.
- 발행본의 내용과 SHA-256, 발행 시각, 수령 확인을 보존한다. 발행한 문구 수정은 새 개정 초안으로 처리한다. 회사 기본 서식 변경은 이미 발행한 계약을 변경하지 않는다. A4 한 장 서식은 자유 입력 문구 합계 700자 이내에서 발행하며, 긴 초안은 저장 후 줄여서 발행할 수 있다. 본문은 9.2pt, 표는 9pt로 인쇄한다.
- 직원 → 근로계약서 또는 내 정보 → 근로계약서: 사본 열람, 팝업 확인, A4 세로 인쇄, HTML 사본 저장. 내용·사본 확인은 임금 변경 동의나 쌍방 서명 완료가 아니다. 계약서의 서명란에 당사자가 서명하고 체결본을 교부한다.
- 관리자 → 직원 목록/직원 등록: 인사기록카드 편집. 미입력 정보는 실제 자료로 보완한다. 직원은 본인 정보만 조회한다.
- 관리자 → 급여·지급: 지급일, 산정기간, 주별 법정 주휴 산정, 지급·공제 세부 항목 및 계산 근거 입력 후 게시. 직원 → 가지급명세서: 게시본 확인과 정정 요청.

## 임금 계산의 의미

합산 기준이 15,000원인 시급제의 구분 표시는 기본시급 12,500원과 시간당 주휴·지원 환산액 2,500원이다. 인사정보 저장 또는 웹 확인 클릭으로 기존 기본시급 15,000원 약정을 일방적으로 낮추지 않는다. 별도 유효한 사전 합의 및 적용일을 확인한다. 계약서 변경은 인사 급여액이나 과거 급여를 자동 변경하지 않는다.

주별 기본급은 기본시급 × 인정 근로시간이며, 주휴·지원 보장 기준은 시간당 환산액 × 해당 주 인정 근로시간이다. 법정 주휴액은 실제 근로시간만으로 단정하지 않고 소정근로시간, 개근 및 적용 요건을 검토하여 관리자가 입력한다. 주휴가 발생하지 않는 주에도 회사 보장 기준만큼 회사 약정수당을 지급한다. 법정액이 보장 기준을 넘으면 초과액을 추가 지급한다. 월 경계의 주휴는 지급 귀속을 확인하여 중복 반영하지 않는다.

연장·야간·휴일근로 및 유급휴가 등 별도 지급 항목은 각 시간·금액·계산법을 적는다. 신규 상세 명세서는 사전 약정 확인과 주별 산정 확인, 항목별 근거가 있어야 게시할 수 있다. 기존에 게시·확인한 명세서는 임의로 세부 내용을 만들어 넣거나 금액을 소급 변경하지 않는다.

## 구성

`contracts.php`, `personnel.php`, `pay-statements.php`는 PHP가 조회·계산·검증·권한 확인·저장을 처리하고 HTML을 출력한다. 입력은 POST와 CSRF, 수정 버전 검사, 저장 후 이동을 사용한다. JavaScript는 기존 화면에서 해당 PHP 메뉴로 이동, 계약서 팝업, 인쇄 기능에만 사용한다. 다른 기존 영업·지도 화면의 스크립트는 기존 기능을 유지한다.

## 운영 인사기록 수정·확정 및 이력 (2026-10-01)

관리자 인사·출결의 인사기록카드에서 인사정보 수정 → 수정 확정으로 내용을 저장한다. 카드 아래 인사기록 수정이력은 기본 닫힘이며, 한국 시간 기준 날짜·시간과 수정자·기록 버전을 표시한다. 날짜를 누르면 당시 입력 내용을 별도 팝업으로 조회한다. 팝업의 이 내용으로 수정은 과거 내용을 수정 양식에 불러오며, 수정 확정을 누를 때 현재 기록에 반영한다. 과거 이력은 덮어쓰지 않는다.

첫 수정 때 기존 입력 내용도 최초 수정 전 기록으로 함께 보관한다. 직원 본인의 기본정보 저장도 이력에 남는다. 이력 조회·과거 내용 적용은 관리자 전용이다. 인사정보와 이력은 같은 트랜잭션으로 저장하고 기존 revision 검사로 동시 수정을 보호한다. 기존 지급·확정 급여와 계약서 스냅샷은 별도로 보존한다.

승인된 직원은 내정보의 근로계약서 앞 정보수정에서 이름·연락처·생년월일·주소·급여계좌 및 선택 정보를 작성한다. 저장 후 내정보로 돌아가 저장 완료를 표시한다. 팀·직책·급여 기준·계약 조건·관리 메모는 직원이 수정할 수 없다.

## 직원 관리 및 화면 정리 (2026-10-01 추가)

- 인사기록은 토·일 휴일, 익월 15일 급여일을 기본으로 표시한다. 기존 기록의 기본설정 변경 전후는 인사 이력에 남기며, 교부된 계약·명세서와 과거 이력은 수정하지 않는다.
- 기본정보는 관리자 확정 전 직원이 수정할 수 있다. 관리자 확정은 서버에서 수정 잠금을 설정하고, 수정권한 해제 후 다시 입력할 수 있다. 계정 사용중지/재개는 기존 인사·실적 기록을 유지한다.
- 직원 등록 수정 메뉴에서 등록 요청을 펼쳐 보고 행을 눌러 팝업에서 수정·승인한다. 관리자 저장·승인에는 저장/취소 확인창을 적용한다.
- 10:00 이후 출근 기록은 일괄 승인에서 제외한다. 개별 승인은 관리자만 할 수 있으며 승인자, 시각, 방식과 원래 출근 기록을 보관한다.
- 주소 초성검색은 저장된 시·도/시·군·구/읍·면·동·리 목록을 사용한다. 도로명, 건물번호, 상세주소는 이어서 입력한다.
- 접수 정책은 직원에게 한국시간 당일 등록분만 표시한다. 관리자는 현재 등록 목록과 날짜별 원본 이력을 펼쳐 볼 수 있다.
- 그레이드 화면의 현재 실적 합계에는 진행 주의 계산액을 별도로 표시한다. 급여 정산용 마감 주 합계와 구분하며 확정 명세서는 그대로 둔다. 테스트 계정도 실제 적용일 이력으로 계산한다.
- 주소창은 도메인만 표시한다. 탭별 sessionStorage와 history 상태에 실제 화면 경로를 보관하여 새로고침·뒤로가기·직원/관리자 세션 구분을 유지한다. 서버의 페이지별 인증·권한 검사는 유지한다.
- 정식 오픈을 위한 DB 초기화는 아직 수행하지 않는다. 접속 비밀번호를 소스나 문서에 보관하지 않는다.

- 접수 정책표의 접수 버튼은 첨부한 접수증 형식의 독립 팝업을 엽니다. 남색 제목줄, 상담원/날짜·시간/성함/010 전화번호/생년월일/성별/지역/통화 가능시간/방문/월보험료/메모 표와 저장·초기화·종료 버튼을 사용합니다.
- 날짜는 현재 연도의 MMDD 입력을 검증하고, 생년월일은 달력으로 입력합니다. 지역 초성검색과 나이별 당일 정책 조회는 유지합니다. 저장 후 성공 안내를 표시하고 초기화하면 새 요청번호로 다음 접수를 입력합니다.
- 성별·통화 가능시간·방문 내용과 서버 등록시각은 추가 테이블 `sales_receipt_details`에 저장됩니다. 기존 접수 자료는 보존합니다. 직원 가접수 수정, 관리자 접수 상세·수정 및 CSV 조회에도 연결됩니다.

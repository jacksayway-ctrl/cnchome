# 근로계약 · 인사기록 · 명세서 운영

2026-09-29 반영. 고용노동부 2025년 표준근로계약서와 임금명세서 안내의 항목을 참고한 회사용 양식이다. 실제 조건 입력과 당사자의 유효한 합의가 필요하며, 화면의 확인 버튼은 서명을 대신하지 않는다.

## 메뉴와 처리

- 관리자 → 인사·출결 → 근로계약: 사업장 기본 서식 저장 → 직원 초안 작성 → 실제 근로일별 시간·임금·기간 확인 → 발행.
- 발행본의 내용과 SHA-256, 발행 시각, 수령 확인을 보존한다. 발행한 문구 수정은 새 개정 초안으로 처리한다. 회사 기본 서식 변경은 이미 발행한 계약을 변경하지 않는다. A4 한 장 서식은 자유 입력 문구 합계 700자 이내에서 발행하며, 긴 초안은 저장 후 줄여서 발행할 수 있다. 본문은 9.2pt, 표는 9pt로 인쇄한다.
- 직원 → 근로계약서 또는 내 정보 → 근로계약서: 사본 열람, 팝업 확인, A4 세로 인쇄, HTML 사본 저장. 내용·사본 확인은 임금 변경 동의나 쌍방 서명 완료가 아니다. 계약서의 서명란에 당사자가 서명하고 체결본을 교부한다.
- 관리자 → 직원 목록/직원 등록: 인사기록카드 편집. 미입력 정보는 실제 자료로 보완한다. 직원은 본인 정보만 조회한다.
- 관리자 → 급여·지급: 지급일, 산정기간, 주별 법정 주휴 산정, 지급·공제 세부 항목 및 계산 근거 입력 후 게시. 직원 → 가지급명세서: 게시본 확인과 정정 요청.

## 임금 계산의 의미

합산 기준이 15,000원인 시급제의 구분 표시는 기본시급 12,500원과 시간당 주휴·지원 환산액 2,500원이다. 인사정보 저장 또는 웹 확인 클릭으로 기존 기본시급 15,000원 약정을 일방적으로 낮추지 않는다. 별도 유효한 사전 합의 및 적용일을 확인한다. 계약서 변경은 인사 급여액이나 과거 급여를 자동 변경하지 않는다.

주별 기본급은 기본시급 × 인정 근로시간이며, 주휴·지원 보장 기준은 시간당 환산액 × 해당 주 인정 근로시간이다. 법정 주휴액은 실제 근로시간만으로 단정하지 않고 소정근로시간, 개근 및 적용 요건을 검토하여 관리자가 입력한다. 주휴가 발생하지 않는 주에도 회사 보장 기준만큼 회사 약정수당을 지급한다. 법정액이 보장 기준을 넘으면 초과액을 추가 지급한다. 월 경계의 주휴는 지급 귀속을 확인하여 중복 반영하지 않는다.

연장·야간·휴일근로 및 유급휴가 등 별도 지급 항목은 각 시간·금액·계산법을 적는다. 신규 상세 명세서는 사전 약정 확인과 주별 산정 확인, 항목별 근거가 있어야 게시할 수 있다. 기존에 게시·확인한 명세서는 임의로 세부 내용을 만들어 넣거나 금액을 소급 변경하지 않는다.

## 구성

`contracts.php`, `personnel.php`, `pay-statements.php`는 PHP가 조회·계산·검증·권한 확인·저장을 처리하고 HTML을 출력한다. 입력은 POST와 CSRF, 수정 버전 검사, 저장 후 이동을 사용한다. JavaScript는 기존 화면에서 해당 PHP 메뉴로 이동, 계약서 팝업, 인쇄 기능에만 사용한다. 다른 기존 영업·지도 화면의 스크립트는 기존 기능을 유지한다.

| 지급 계좌·지급용 엑셀 | 신규 메뉴. 은행·계좌번호·예금주 등록·수정, 목록 마스킹, 변경 사유·전후 이력 |
| 지급 대상 검토 | 선택 급여 중 확정·미지급만 포함. 계좌 누락 항목과 상태별 제외 사유 표시. 최신 계좌와 확정 금액 사용 |

| 명세서 수정 | 확정 취소 시 이전 공개 금액을 ‘수정 중’으로 보존·상세 조회. 재공개 시 이전 표시 해제 |
| 출결 일괄 반려 | 공통 사유 필수, 대기 건만 반영. 본인 신청·이미 처리된 신청은 제외 사유 표시 |
| 정정 요청 대리 접수 | 확정·지급 완료 급여를 선택해 직원별·월별로 접수, 관리자 알림·이력 기록 |
| 일 그레이드 내역 | 현재 조회 조건의 별도 XLSX 다운로드. 월 급여·주휴수당에 영향 없음 |
| 운영 점검 | 확정 미지급 급여의 계좌 누락 건수를 업무 메뉴와 연결 |

검증: 관련 테스트 47개 및 관리자 19개 경로의 DOM 처리 흐름 검사. 계좌 최신값 반영, 중복 선택 제거, 누락 제외, 지급 경계별 취소, 일괄 반려, 대리 접수, 별도 다운로드를 확인한다.

현재는 **합성 데이터 미리보기**이며 업무 데이터는 메모리에만 남는다. 실제 계좌·개인정보를 입력하지 않는다. 서버 로그인·접근 통제·영구 저장·실제 이체·전자서명 등은 기존 후속 범위로 남겨 두었다. 실제 브라우저 시각 검증은 별도다.

아래는 이전 점검 이력이며, 메뉴 수와 구현 범위는 위 내용이 우선한다.

# 2026-09-25 일 그레이드 수정

사용자의 최신 지시가 아래 9월 24일 검토 기록보다 우선한다.

- 관리자 메뉴는 총 18개. 기존 일수당 메뉴를 **TM 일 그레이드**로 변경하고 **일 그레이드 지급 내역**을 추가했다.
- TM 상담원만 집계·지급 가능. 팀장·관리직·관리자는 제외한다.
- 당일 입력은 해당 날짜만 수정하고, 현재 일 표의 최고 달성수당만 자동 계산한다. 건당 추가수당은 제외한다.
- 한국 시간 자정에 화면을 새 날짜의 0건·0원으로 전환한다. 날짜별 과거 기록은 유지하며 다음 날로 이월하지 않는다.
- 급여 합산·현금 기지급 차감·급여 확정에 따른 지급 차단을 제거했다. 급여 명세·급여대장 XLSX에도 포함하지 않는다. 주휴수당으로 연결되는 항목은 없다.
- 아래의 급여 합산·확정 후 현금 지급 제한 설명은 이전 구현 이력으로 대체되었다.
- 데이터는 여전히 메모리 기반 미리보기다. 페이지를 새로고침하면 초기화되며 실제 DB·접수 자동 집계는 미연결이다.

# 관리자 메뉴 점검 및 보완

2026-09-24 · 사용자 요청: 관리자에게 필요한 추천 기능을 넣고 빠진 메뉴 추가.

기존 관리자 메뉴 8개를 업무·인사/급여·운영 3그룹의 17개로 정리했다. 기존 접수 정책·지역·그레이드 편집은 유지했다. 새 화면은 합성 데이터로 처리 흐름을 검토하는 미리보기이며 실제 업무 서버는 연결하지 않았다.

## 추천 구현 판단

- 진행 중 A/S의 유일한 차감 결정을 사유와 함께 철회하면 차감 근거가 없어져 복구한다. 완료된 유효 A/S와 남은 문제의 전체 해결 조건은 별도로 유지한다.
- 활성 최고관리자를 최소 한 명 유지하여 관리자 권한을 모두 잃는 설정을 막는다.
- 월 급여가 확정된 일수당은 중복 지급을 방지하기 위해 현금 지급 기록 추가를 막는다.
- 목록 검색 조건을 변경하면 기존 선택을 해제하여 숨겨진 대상의 일괄 처리를 방지한다.
- 엑셀의 사용자 입력 문자열은 수식이 아닌 문자열 셀로 기록한다.

이는 사용자가 위임한 추천안 선택에 따른 미리보기 구현 판단이다. 기존 명시적 결정과 법정 산식의 검토 보류는 유지한다.

## 범위와 제한

- 새 업무 데이터는 페이지 메모리 안에서만 유지한다. 실제 이름·계좌·계약·증빙을 입력하지 않는다. 초기화 시 복구되는 영구 저장이나 실제 승인·송금 기능은 없다.
- 새 화면의 검토 기준일은 2026-10-15, 급여 귀속 월은 2026-09인 고정 시나리오다. 기존 직원·실적 화면의 예시와 자동 집계로 연결된 상태가 아니다.
- 급여 금액은 고정 예시다. 전체 운영 기준에 따른 실제 실적 집계·급여 재계산은 구현되지 않았다. 별도 계산 검토 화면과 [급여 구현 현황](PAYROLL_IMPLEMENTATION.md)을 참조한다.
- XLSX 다운로드는 예시 월 급여대장이다. 실제 지급 계좌용 엑셀, 계약서/PDF 생성, 첨부 보관, 직원 서명, 인사 이동·퇴사 및 재입사 자동 처리는 후속 구현이다.
- 새 권한 설정은 실제 인증·접근 통제가 아니다. 서버 보안 작업의 기존 보류를 해제하지 않는다.
- 달력·연차 데이터는 법정 공휴일 또는 법정 발생분을 사전 검증한 자료가 아니다. 주휴 포함 시급 구성·연차 기준 임금도 기존 문서 검토 대기를 유지한다.

# 관리자 메뉴 점검 및 보완

2026-09-24 · 사용자 요청: 관리자에게 필요한 추천 기능을 넣고 빠진 메뉴 추가.

기존 관리자 메뉴 8개를 업무·인사/급여·운영 3그룹의 17개로 정리했다. 기존 접수 정책·지역·그레이드 편집은 유지했다. 새 화면은 합성 데이터로 처리 흐름을 검토하는 미리보기이며 실제 업무 서버는 연결하지 않았다.

## 메뉴별 반영

| 메뉴 | 점검 결과 | 이번에 제공하는 동작 |
| --- | --- | --- |
| 관리자 홈 | 처리 대기 업무 진입점 부족 | 출결·A/S·급여·계약 대기 건수, 업무함 바로가기. 기존 팀별 달력·직원 현황 유지 |
| 접수 관리 | 기존 정책 편집 유지 | 기존 거래처·접수 코드·지역 정책 화면 유지 |
| 실적 관리 | A/S 등록과 차감이 한 번에 처리되는 이전 예시 | 직접 차감 토글 제거, 별도 A/S 검토 메뉴 연결. 기존 집계는 별도 예시임을 표시 |
| A/S 관리 | 설명 표만 존재 | 문제별 복수 A/S, 담당자 변경, 경과 메모, 차감 결정, 완료·오류 취소, 복구 조건, 알림·이력 |
| 직원 관리 | 계약·연차·급여로 이동 불편 | 관련 업무 바로가기. 신규 직원은 새 계약·연차 메뉴의 대상에도 반영 |
| 출결 승인 | 설명 표만 존재 | 검색·필터, 개별 검토·반려·승인 취소, 일괄 승인, 잔여 연차·본인 승인·시간 중복 검사 |

| 근로계약 | 메뉴 없음 | 계약 조건 등록, 기간 검증, 서명 대기 흐름, 종이 서명 확인·서명본 미등록 구분 |
| 그레이드 관리 | 기존 편집 기능 존재 | 이전 참고표 편집과 새 계산 검토 링크 유지 |
| 일수당 지급 | 메뉴 없음 | 전액 지급 확인, 실제 지급일, 기지급 보호, 월 급여 기지급 반영 |
| 급여·지급 | 계산 검토 링크만 존재 | 공제·임금 기준 검토, 확정 조건·제외 사유, 일괄 확정·공개·지급, 확정 금액 스냅샷, XLSX 급여대장 |
| 정정·별도 정산 | 메뉴 없음 | 정정 요청 검토·답변, 정정 완료 시 차액 정산 생성, 분할 지급, 초과 지급 표시, 지급 기록 오류 정정 |
| 계정·권한 | 메뉴 없음 | 최고·급여·출결 권한 설정 예시, 이용 상태, 마지막 활성 최고관리자 보호 |

| 변경 이력 | 설명만 존재 | 현재 미리보기에서 수행한 변경의 작업자·시각·사유·전후 JSON 비교, 검색 |
| 운영 점검 | 메뉴 없음 | 실제 대기 건수에 연결된 점검 목록과 운영 준비 항목 |

## 추천 구현 판단

- 진행 중 A/S의 유일한 차감 결정을 사유와 함께 철회하면 차감 근거가 없어져 복구한다. 완료된 유효 A/S와 남은 문제의 전체 해결 조건은 별도로 유지한다.
- 활성 최고관리자를 최소 한 명 유지하여 관리자 권한을 모두 잃는 설정을 막는다.
- 월 급여가 확정된 일수당은 중복 지급을 방지하기 위해 현금 지급 기록 추가를 막는다.
- 목록 검색 조건을 변경하면 기존 선택을 해제하여 숨겨진 대상의 일괄 처리를 방지한다.
- 엑셀의 사용자 입력 문자열은 수식이 아닌 문자열 셀로 기록한다.

이는 사용자가 위임한 추천안 선택에 따른 미리보기 구현 판단이다. 기존 명시적 결정과 법정 산식의 검토 보류는 유지한다.

## 범위와 제한

- 새 업무 데이터는 페이지 메모리 안에서만 유지한다. 실제 이름·계좌·계약·증빙을 입력하지 않는다. 초기화 시 복구되는 영구 저장이나 실제 승인·송금 기능은 없다.
- 새 화면의 검토 기준일은 2026-10-15, 급여 귀속 월은 2026-09인 고정 시나리오다. 기존 직원·실적 화면의 예시와 자동 집계로 연결된 상태가 아니다.
- 급여 금액은 고정 예시다. 전체 운영 기준에 따른 실제 실적 집계·급여 재계산은 구현되지 않았다. 별도 계산 검토 화면과 [급여 구현 현황](PAYROLL_IMPLEMENTATION.md)을 참조한다.
- XLSX 다운로드는 예시 월 급여대장이다. 실제 지급 계좌용 엑셀, 계약서/PDF 생성, 첨부 보관, 직원 서명, 인사 이동·퇴사 및 재입사 자동 처리는 후속 구현이다.
- 새 권한 설정은 실제 인증·접근 통제가 아니다. 서버 보안 작업의 기존 보류를 해제하지 않는다.
- 달력·연차 데이터는 법정 공휴일 또는 법정 발생분을 사전 검증한 자료가 아니다. 주휴 포함 시급 구성·연차 기준 임금도 기존 문서 검토 대기를 유지한다.

## 검증

```sh
node --test admin-workspace.test.cjs payroll-engine.test.cjs grade-settings.test.cjs
npm install --prefix /tmp/cnchome-admin-test jsdom@30.1.1 --no-audit --no-fund
NODE_PATH=/tmp/cnchome-admin-test/node_modules node scripts/check-admin-dom.cjs
```

- 핵심 업무 규칙 및 관련 기존 계산 테스트 40개 통과.
- DOM 검증: 관리자 17개 경로, 활성 메뉴, 승인 중복 차단·연차 복구, 복수 A/S 완료, 확정 전 달력 검사, 공개 후 지급, 일수당, 계약 입력 문자열 이스케이프, 마지막 관리자 보호, 정정·분할 지급·오류 수정, 감사 기록·알림, 기존 직원 경로.
- XLSX를 ZIP CRC 검사와 openpyxl로 다시 읽어 한글·숫자·수식 형태 문자열 보존을 확인했다.
- Chromium 설치 파일 다운로드가 손상되어 실제 브라우저 렌더링·모바일 시각 검증은 수행하지 못했다. DOM 검증은 스크린샷 검증을 대신하지 않는다.

# 관리자 접수관리

관리자 홈 다음에 접수관리 메뉴를 두며, 기존 영업 관리의 접수 메뉴를 이곳으로 옮긴다. 실적과 A/S 메뉴는 기존 위치를 유지한다.

`/intake.php?role=admin`은 PHP 조회·폼 저장 방식이다. 월, 날짜 범위, 담당 직원, 부서, 상태, 운영/테스트 구분, 고객·전화·코드·상담 장소 검색을 지원한다. 목록은 30건씩 표시하며 CSV는 현재 조건 전체를 내려받는다. CSV 수식 입력을 무력화하고 모든 출력에 HTML 이스케이프를 적용한다.

접수 등록은 기존 `sales_mutate`를 사용하고 가접수로 생성한다. 중복 제출 키로 재전송 시 중복 생성을 막는다. 기존 직원 실적·달력·그레이드에서 사용하는 동일 DB를 사용하므로 상태 변경은 다른 화면 조회에도 반영된다.

상세 화면에서 가접수/정상접수/A/S 상태와 고객·상담 정보, 메모를 수정한다. 담당자·최초 접수일·생년 정보는 상세 수정에서 변경하지 않는다. 같은 전화번호의 이달 접수는 경고로 표시하며 자동 삭제하지 않는다.

관리자 권한, CSRF, 버전 충돌 검사를 적용한다. 상태·정보 수정과 이전/이후 값·처리자·시각·메모 기록을 같은 트랜잭션으로 저장한다. 과거 등록·상태 기록도 상세 이력에서 함께 표시한다. 예전 JSON 테스트 자료는 상태만 변경하며 새 변경 이력을 남긴다. 실데이터는 기본 조회에서 테스트 자료와 분리한다.

접수 요약에는 **가접수일 기준 접수 건수**와 **실제 접수일 기준 접수 건수**를 함께 표시한다. 두 값 모두 현재 정상접수 상태의 접수증 수량이며, 급여 실적의 중복 제외와는 별개다. 첫 기준은 최초 콜 날짜, 두 번째 기준은 저장된 정상접수 상태 변경일(한국 시간)을 사용한다. 날짜가 저장되지 않은 기존 자료는 최신 상태 변경 이력의 UTC 시각을 한국 날짜로 변환하며, 이력이 없는 자료는 최초 날짜를 유지한다. 지난달 콜을 이번 달에 접수한 건도 실제 접수일의 월에 포함한다. 각 수량을 누르면 같은 기준과 월·날짜 범위·부서·직원·자료 구분·검색어로 목록을 조회하며, 실제 날짜 조회는 최초 가접수일도 함께 표시한다. CSV에는 두 날짜를 나란히 기록한다.

전체 접수 실적 달력은 세 부서의 실제 일별 수치와 월 합계를 유지한다. 미래 날짜와 비영업일에는 일별 수치나 0건을 표시하지 않는다. 저장된 관리자 영업일을 우선하고, 별도 저장이 없으면 주말·공휴일·회사 지정 휴일을 제외한다. 명시적으로 영업일에 선택한 주말·휴일은 지난 날짜에 한해 수치를 표시한다. 이 표시 규칙은 원본 접수, 실적 합계, 급여 계산을 변경하지 않는다. 공휴일 이름은 계속 표시한다. 2026·2027년의 초기 HTML 공휴일은 `server/config/public-holidays.json`과 `public-holidays.js`의 확인된 날짜를 함께 유지한다.

접수 목록의 연결 오류는 5초 갱신 주기에 따라 자동 재조회한다. 서버 자동 배포는 실패한 커밋도 60초부터 최대 900초 간격으로 다시 시도하며, 새 커밋은 대기 시간 없이 다음 확인 주기에 배포한다. 배포 잠금, 사전 검증, 백업, 버전 확인, 보존형 마이그레이션은 그대로 적용한다.

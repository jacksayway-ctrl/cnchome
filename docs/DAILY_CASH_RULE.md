# 일 그레이드 별도 현금 관리 · 2026-09-26 정정

최신 요청에 따라 보험의 일 그레이드를 최고 구간 정액 수당에서 시작 건수 포함 건당 현금 지급으로 변경한다.

- 시작 6건, 건당 5,000원, 상한 없음.
- 0~5건: 0원 / 6건: 5,000원 / 7건: 10,000원 / 8건: 15,000원 / 100건: 475,000원.
- 계산식: max(0, 정상 실적 건수 − 시작 건수 + 1) × 건당 지급액.
- 입력표는 시작 건수와 건당 금액을 담은 한 줄만 표시한다. 종료 구간, 행 추가·삭제, 시급·정액 달성수당 입력은 일 그레이드에서 제거한다.
- 상품별 설정은 분리 유지한다. 보험은 위 기본값을 적용하며, 별도 금액을 정하지 않은 화장품·식품은 건당 0원으로 둔다.
- 과거 보험 참고표를 읽을 때 새 일 현금 규칙을 보완한다. 주·월 표는 그대로 보존한다. 이미 기록된 과거·기지급 내역은 변경하지 않는다.
- 매일 0건에서 시작하며 관리자 현금 관리 내역으로만 집계한다. 주·월 그레이드 계산, 월 급여·주휴수당·명세서·급여대장에 합산하거나 차감하지 않는다. 실제 현금 지급·이체를 실행하는 기능은 아니다.

이 문서의 기준이 이전 ‘최고 구간 달성수당’ 설명에 우선한다. 기존의 미리보기·브라우저 저장 범위는 유지한다.

# 주 그레이드 초안 · 2026-09-26

보험 주 그레이드를 주간 일평균 정상 실적 기준의 한 줄 표로 표시한다.

| 6건 미만 | 6건 이상~7건 미만 | 7건 이상~8건 미만 | 8건 이상 |
| --- | --- | --- | --- |
| 0원 | 30,000원 | 35,000원 | 40,000원 |

달성한 최고 구간의 정액만 한 번 적용하며 건수에 곱하지 않는다. 주수당은 급여일에 합산하는 기준이고 일 그레이드 별도 현금과 구분한다.

보험 탭에서 이전 버전 기준을 처음 편집하면 위 초안을 보여준다. 기존 브라우저 저장 이력과 과거 지급 기록은 자동으로 덮어쓰지 않으며 ‘변경 내용 확인 → 확인 후 적용’으로 새 기준을 저장한다. 화장품·식품은 별도 기준을 유지한다.

주 표는 가로 한 줄에 금액을 입력한다. 직원 참고표와 저장 확인 화면도 같은 배열로 표시한다. 현재는 참고표 미리보기이며 실제 급여 통합 서버 자동 반영은 미연결이다.

## 표시·설정 보완

- 표 제목은 ‘6건’, ‘7건’, ‘8건’처럼 기준 건수만 표시한다.
- 각 기준의 건수와 금액을 수정할 수 있고 기준 추가·삭제를 지원한다. 최대 20개이며 20개일 때 추가 버튼을 비활성화한다.
- 첫 기준 미달 0원 구간은 내부 계산용으로 유지하며 20개 제한에 포함하지 않는다.
- 건수는 양의 정수·오름차순으로 입력해야 한다. 중복·역순을 검증하고 종료 경계는 다음 기준에 맞춰 자동 계산한다.
- 표는 가로 한 줄을 유지하고 기준이 많으면 가로로 스크롤한다.
- 20개 허용·21개 차단, 기준 추가·삭제·수정, 변경 기준에 따른 최고 달성 구간 계산을 검증했다.

## 연속 20칸 자동 생성으로 변경

시작 건수·시작 금액·칸마다 증가액을 입력하면 20칸 전체를 생성한다. 기본 증가액은 5,000원이며 건수는 1씩 증가한다. 6건 30,000원 시작 시 25건 125,000원까지, 7건 시작 시 26건까지 만든다. 개별 칸 추가·삭제 방식은 자동 생성 방식으로 대체한다. 스크롤 영역에 건수와 금액을 함께 표시하며 가로 스크롤바 스타일을 제공한다.

## 시작 건수 및 일 표

주 편집표는 8건부터 27건까지 20칸으로 시작한다. 기존 지급액 30,000원에서 칸마다 5,000원 증가한다. 일 표도 가로 스크롤 20칸이며 기본 6건 5,000원, 7건 10,000원부터 25건 100,000원까지 표시한다. 일수당은 20칸 이후에도 상한 없이 건당 계산한다. 시작 건수·금액 변경은 표에 즉시 표시되고 기존 저장 절차를 따른다.

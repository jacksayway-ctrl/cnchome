# 상품별 그레이드

관리자 그레이드 기준표에 보험·화장품·식품 선택 버튼을 제공한다. 각 상품의 일·주·월 표, 적용 시작일, 변경 이력과 계산 미리보기는 독립적이다. 탭을 이동해도 수정 중인 표는 해당 탭에 남으며, 저장하지 않은 내용은 새로고침 시 사라진다.

- 기존 상품 구분 없는 저장 기준과 기본 예시 표는 보험에만 적용한다.
- 화장품·식품의 미등록 표는 전체 구간 0원으로 시작한다. 보험 금액을 임의 복제하지 않는다.
- 상품 키는 보험 insurance, 화장품 cosmetics, 식품 health다. 직원 정보의 건강보조식품 부서와 식품 탭을 연결한다.
- TM 일 그레이드 계산은 관리자의 선택 탭이 아닌 직원 부서로 결정한다. 당일 기록에 부서를 보존하여 다른 탭 편집이나 이후 소속 변경에 따른 교차 적용을 방지한다.
- 확정·기지급·과거 일 그레이드 기록을 소급 변경하지 않는다. 일 그레이드는 여전히 급여·주휴수당과 별도다.
- 기존 브라우저 저장 키를 유지하며, 각 변경 기록에 department를 추가한다. 상품명이 없는 과거 기록은 보험으로 읽는다. 저장 시 다른 상품 기록도 보존한다.

현재 기준표는 브라우저의 참고표이며 실제 급여 통합 서버에 적용되는 것은 아니다. 주·월 계산 미리보기에는 기존 참고 계산 방식이 남아 있고, 전체 확정 운영 규칙의 급여 엔진 연결은 별도 작업이다.

검증: 상품별 저장·이력 분리, 다른 탭 초안 유지, 보험 기존 값 보존, 미래 적용일, 미등록 상품 0원, 보험·화장품 직원의 서로 다른 일수당, 기록일 부서 사용을 검사한다.

# 직원 등록·수정

인사·출결의 직원 목록에서 전체 가상 직원 16명과 정보 보완 필요 여부를 확인한다. 실제 직원 명단은 제공되지 않았으므로 추가로 만들지 않았다. 직원 등록 하위 페이지에서 새 직원을 등록하거나 목록의 상세·수정으로 기존 정보를 보완할 수 있다.

| 구분 | 항목 |
| --- | --- |
| 기본정보 | 이름·연락처(필수), 사번·이메일 |
| 소속·재직 | 소속 부서·팀, TM 상담원·팀장·관리직, 입사일, 재직·휴직·퇴사, 마지막 재직일 |
| 근무 조건 | 평일 근무요일, 토·일 중 주휴일; 공통 근무·점심·휴게 안내 |
| 급여 기준 | 시급제·월급제, 기본시급 또는 월 기본급; 직책별 주휴 포함 여부 안내 |
| 계약·비고 | 무기계약·기간제, 기간제 종료일, 관리 메모 |

급여 기준액은 미정 상태로 둘 수 있으며 목록에서 보완 대상으로 표시한다. 중복 사번, 잘못된 날짜, 입사 전 퇴사일, 기간제 종료일 누락, 근무요일·주휴일 누락, 상담원·팀장의 월급제 선택을 검사한다. 사번이 없는 기존 직원은 미설정으로 표시한다.

지급 계좌, 계정·관리 권한, 계약서 작성·서명, 연차 내역은 각각 기존 전용 메뉴에서 관리한다. 직책을 관리직으로 설정해도 관리자 권한이나 로그인 계정이 자동 생성되지는 않는다.

현재는 미리보기다. 등록·수정은 페이지 메모리와 예시 직원 목록에만 반영되며 새로고침하면 초기화된다. 입력한 급여 기준의 실제 급여 자동 계산 연결, 인사정보 적용일별 이력 계산, 팀 조직 관리, 실제 계정 발급은 별도 구현이 필요하다. 변경 이력은 화면에서 기록하며 기존 확정 급여 예시는 변경하지 않는다.

## 직원 정보와 계약 초안 연결 보완

- 인적사항: 선택 생년월일, 주소 추가. 주민등록번호·비밀번호는 수집하지 않는다.
- 배치·업무: 근무장소와 담당업무 추가.
- 계약·임금: 계약 시작일, 임금 적용일, 월급제 무급 차감용 시급 추가.
- 직원 상세에 이 직원의 계좌(번호 마스킹), 계약·급여 바로가기, 출결 신청, 잔여 연차, A/S·정정·정산·일 그레이드 건수를 표시한다. 계정은 실제 로그인 서버 미연결 상태로 표시한다.
- 계약 메뉴에서 회사명·대표자·사업자번호·주소·연락처를 설정한다. 미등록 값은 가짜 값으로 채우지 않는다.
- 직원 상세의 ‘저장된 직원 정보로 계약 작성’ 또는 계약 메뉴에서 직원을 선택하면 인적사항·근무·급여·계약 조건을 불러온다. 저장하지 않은 직원 편집 내용은 포함하지 않는다.
- 계약 초안에는 명시적으로 선택한 항목만 복사한다. 직원 관리 메모는 제외한다. 회사 정보와 직원 정보, 근무요일 등은 복제하여 이후 수정이 기존 계약에 영향을 주지 않도록 한다.
- 미등록 필수 정보를 초안에 표시하며 정보 보완 전에는 새 초안의 서명 요청 상태 전환을 차단한다. 계약 시작·종료일과 임금 조건 요약은 초안 저장 시 검토·수정할 수 있다.
- 기존 예시 계약에는 과거 직원 정보가 없어 스냅샷 없음으로 안내한다. 기존 예시 상태 흐름은 유지한다.

이번 보완은 정보 자동 채움과 계약 조건 초안 보존까지다. 최종 계약서 법률 문구, 주휴 시급 구분 산식, 미사용 연차수당 기준은 미확정이며, 실제 전자서명·PDF 생성·영구 저장은 연결하지 않았다. 초안은 완성된 근로계약서나 법률 검토 완료 문서가 아니다.

# 부서별 정책·그레이드·급여 관리

영업관리(정책), 그레이드, 급여·정산은 보험 / 화장품 / 건강보조식품 탭을 사용한다. 하위 페이지 이동 시 선택한 부서를 유지한다. 실제 경로는 `CNCPageNavigation.url()`에서 읽으며 주소창 숨김 후에도 부서가 초기화되지 않는다.

- 정책: 기존 최상위 정책·거래처·코드는 보험으로 보존한다. 나머지 부서는 `intake_policy_state.state.departments` 아래 독립 저장한다. 공통 revision으로 동시 저장 충돌을 검사하고 변경 이력의 `_changedDepartment`로 조회 범위를 구분한다. 직원 조회는 인증된 소속으로 고정하며 수량 감소 공지도 해당 부서에만 보낸다.
- 그레이드: 기존 부서별 지급 기준과 저장 방식을 유지한다. 상단 부서 탭과 기준표·일별 지급 내역을 연결한다. 보험 외 부서는 등록된 전용 기준만 적용하며 임의의 보험 기준을 복사하지 않는다.
- 실적·A/S: 영업관리에서 선택 부서의 실제 접수 상태를 조회·변경한다. 관리자 홈은 기존 전체 현황을 유지한다.
- 급여: 명세서 목록, 작성 대상, 지급 계좌와 정정 내역을 부서별로 조회한다. 작성·게시 시 선택한 부서를 서버에서 검사한다. 새 산정 기록은 `calculation.department`에 부서를 저장하고 게시 시에도 보존한다. 기존 기록은 현재 직원 소속을 기준으로 조회하며 금액을 다시 계산하거나 변경하지 않는다.
- 정산 항목: 각 명세서의 지급·공제 항목별 금액과 계산 방법을 개별 입력한다. 기존 보험 산식은 유지한다. 화장품·건강보조식품의 별도 자동 정산 산식은 사용자가 구체적으로 지정한 뒤 추가한다. 미설정 부서의 계산 검토 화면에 보험 예시를 대신 표시하지 않는다.

배포 검증은 기존 격리 검사에 정책/거래처/이력/공지의 부서 간 분리, 직원의 다른 부서 조회 방지, 저장된 급여 부서 보존 및 탭 연결 검사를 포함한다. 운영 DB에 테스트 자료를 추가하지 않는다.

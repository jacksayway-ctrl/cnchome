# 근로계약 승인과 가접수 알림

## 근로계약

인사·출결 → 근로계약에서 계약 시작일과 5일, 1개월, 3개월, 직접 입력, 무기계약을 선택한다. 5일은 계약서에 지정된 근무요일을 다섯 번 포함하는 날짜까지이며 공휴일 예외는 직접 입력으로 조정한다. 월 단위는 다음 기간의 같은 날짜 전날까지이며 해당 날짜가 없으면 해당 월 말일을 사용한다. 계산은 PHP에서 수행하며 스크립트는 날짜 미리보기만 갱신한다.

첨부 양식의 씨앤씨 사업장 정보와 매월 15일 지급을 새 회사 서식의 기본값으로 사용한다. 직원 인사정보에 지급일이 지정된 경우 그 값을 새 초안에 가져온다. 이미 발급한 계약서의 내용과 검증값은 변경하지 않는다.

관리자 초안 작성 → 직원에게 승인 요청 → 직원 본인 성명과 확인 체크로 내용 승인 → 관리자 서명·합의 확인 후 최종 적용 순서로 관리한다. 직원은 사유를 적어 수정 요청할 수 있고 관리자는 적용 전 발급을 회수하거나 개정 초안을 생성할 수 있다. 이전 사본 열람 확인 기록만으로 최종 적용할 수는 없다.

최종 적용은 인사정보의 계약 구분·시작일·종료일·급여일을 갱신한다. 승인 이력과 인사 갱신은 한 트랜잭션으로 저장한다. 수정 번호, 고정된 수신 계정, 최신 적용 계약 버전을 확인하며 기존 급여 명세서와 급여 계산값은 수정하지 않는다. 웹 승인 기록과 별도로 당사자가 서명한 계약서 사본을 보관한다.

## 가접수 알림

관리자 홈의 업무 현황 다음에 가접수 알림을 둔다. 월 제한 없이 미처리 가접수를 조회하고 오래된 순을 기본으로 최신순, 부서, 고객·전화·담당자 검색, 운영/테스트 자료, 유지 처리 여부로 구분한다. 한 페이지에 30건을 표시한다.

활성 화면에서 5초마다 PHP가 렌더링한 목록을 갱신한다. 연결 실패를 표시하며 수동 갱신·일시 중지를 지원한다. 행을 누르면 별도 창에서 고객 상세, 정상접수·A/S 상태 변경, 가접수 유지 사유 및 이력을 관리한다. 상태가 정상접수나 A/S로 바뀌면 다음 갱신에서 가접수 목록에서 제외한다. 두 관리자가 동시에 처리하면 수정 번호로 충돌을 막는다.

## 직원등록과 화면

직원등록은 별도 창에서 A4 한 장으로 인쇄할 수 있는 좁은 서식으로 표시한다. 화면에서는 스크롤을 허용한다. 사번은 오늘 날짜와 다음 순번으로 미리 표시하며 저장 트랜잭션에서 최종 발급한다. 급여일 기본값은 15일이다. 메뉴 글자는 1px 확대하고 영업관리(정책) 명칭 및 주그레이드(해당 주 평균 목표개수) 표현을 적용한다. 관리자 화면의 예전 보험팀 고정 공지 띠는 제거한다.

## 검증

`check-contracts.php`는 기간 계산의 월말·연도 경계, 승인/적용 권한, 수정 번호 충돌, 계정 분리, 변경 불가 사본 및 감사 기록 실패 시 롤백을 확인한다. `check-intake-management.php`는 가접수 유지, 지난달 접수 조회, 정렬, 테스트 분리와 별도 창 링크를 검증한다. `check-personnel.php`는 기본 지급일·사번·개인정보 범위와 저장을 검증한다. 실제 DB를 변경하지 않는 격리된 데이터로 수행한다.

## 검증

- `node --test *.test.cjs`: 86개 통과, 실패 0개. 지역 규칙 파일 내부의 다수 회귀 검사를 포함한다.
- `scripts/check-admin-dom.cjs`: 관리자 19개 경로와 기존 직원 경로, 출결·A/S·급여·계약·정산·권한·알림·이력·XLSX 처리 흐름 확인.
- `scripts/check-payroll-dom.cjs`: 계산·잘못된 입력 후 복구·초기화·일 그레이드 제외·보정 재확인·HTML 문자 처리·운영 기준 검색·관리자 복귀 확인.
- 관리자 DOM 추가 검사: 동일 지급 양식 재제출 차단, 미지급 정정의 월 급여 연결, 보정액 XLSX 출력.
- 실제 XLSX 파일을 openpyxl로 열어 ZIP 무결성, 계좌번호 앞자리 0, 수식 형태 문자열의 텍스트 보존, 한글·XML 문자, 음수 보정액 확인.
- 변경 파일 문법 검사 및 공백 오류 검사.

DOM 검사는 실제 브라우저 렌더링·모바일 시각 검증과 구분한다. 계좌 유효성은 입력 형식 검사이며 은행 계좌 실명·존재 확인이 아니다.

- 페이지 메모리 기반 미리보기. 실제 고객·직원 정보를 입력하지 않는다. 영구 저장·실제 인증·서버 권한·다중 사용자 동시 처리·실제 이체·직원 전자서명은 미연결이다.

- 주휴 포함 시급 구분 산식, 미사용 연차수당 기준 임금, 퇴직급여 제도와 연차사용촉진은 기존 검토·결정 대기다.

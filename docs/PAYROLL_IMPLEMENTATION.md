## 후속 구현

실제 업무 서버·인증·권한 작업은 기존 `SECURITY-ARCHITECTURE.md`에서 보류한 상태다. 이 변경은 보류를 해제하지 않는다.

1. 직원·팀·부서·직책·근로계약·그레이드 버전의 영속 데이터 모델과 서버 권한.
2. 최초 접수일·이전일 예외와 실적 반영일 당시 팀 귀속 집계, 직원/팀장 확정 실적 스냅샷, 재직기간과 동일인을 구분한 중복 방지, 복수 A/S 검토·차감·복구 트랜잭션.
3. 실제 출결 승인·근무일정·유급시간 연결, 주·월 표 버전과 부서·직책 적용 기간 자동 분할.
4. 주휴 포함 시급 구성과 미사용 연차수당 기준 임금의 문서 검토. 임의 산식으로 대체하지 않는다. 연차 자동 발생·최저임금 법정 검증·주휴 계산은 아직 미구현.
5. 확정/취소/재확정, 공개/수정 중 명세서, 지급 완료, 퇴사자 별도 정산 실적 고정, 보정 감사 이력, 알림.
6. 근로계약 서명·직전 비밀번호 확인·버전 보관, 초기 계정 발급, 퇴사/재입사 접근 범위.
7. 관리자 급여대장·지급용 엑셀·PDF, 계좌 누락 처리 및 직원 화면 조회 권한.

퇴직급여 제도·연차사용촉진 운영 여부는 사용자 결정 대기이며 이번 계산 모듈에 임의 구현하지 않는다.

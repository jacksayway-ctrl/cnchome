# 급여 구현 현황

2026-09-24 · 실제 운영 전 단계. 운영 기준과 구현 상태는 구별한다.

## 이번 변경

- `payroll.html`: 입력 즉시 갱신되는 급여 계산 검토 화면. 부서별 기본급·월 수당, 기지급 일수당 보호, 월 경계를 넘는 주 수당 귀속, 공제 대기·음수 실지급액 표시, 보정 재확인, 관리직·겸임 팀장 계산 예시, 운영 기준 검색.
- `payroll-engine.js`: 브라우저·Node에서 공유할 수 있는 순수 계산 모듈. 네트워크·저장소·현재 시각에 의존하지 않는다.
- `payroll-requirements.json` / `.md`: 최신 사용자 답변과 변경 이력 250개. 예시 금액을 실제 회사 그레이드표로 확정하지 않는다.
- 기존 `index.html`에 계산 검토 링크 추가. 이전 그레이드표의 일평균·구간별 초과수당 계산은 참고 자료로 구분한다. 새 엔진으로 자동 이전하거나 과거 자료를 덮어쓰지 않는다.

## 계산 모듈 범위

| 지원 | 입력·결과 |
| --- | --- |
| 일 그레이드 | 최고 달성 구간만, 기지급 보호, 증가·미지급액 분리 |
| 주·월 그레이드 | 표 적용 기간별 실적 입력, 부서·일반직 시간 비율, 기준 최소 1건, 월 최상위 초과수당 |
| 0시간 예외 | 전체 주·월 0시간은 실적으로 계산, 전체는 양수지만 특정 표 기간만 0이면 그 기간 수당 0 |
| 일반직 기본급 | 기본시급 보장, 정수 분 단위 계산, 월 합산 후 한 번 버림 |
| 무급 출결 | 승인된 무급 건별 10분 단위 내림 |
| 관리직 | 재직 달력 비율, 급여 방식 변경 시 재직기간 예정일 비율 단계 적용, 별도 차감용 시급, 수당의 달력 비율 |
| 팀장 | 최고 구간 + 별도 기준 초과분, 팀별 담당 비율 |
| 월 합계 | 각 수당 합산, 현금 일수당·퇴사자 기지급액 차감, 공제 미입력 시 실지급액 미계산, 사유 있는 보정 |
| 확정 조건 | 월 종료, 공제 확인, A/S 검토, 보정·관리직 수당 확인, 음수 차단. 최저임금·임금 구성 검증 결과는 외부 검토 입력이며 자체 검증 기능이 아님 |
| 별도 정산 | 분할 지급 합계·잔여·초과 지급액 표시. 회수 방향의 기록 방식은 미정이라 거절 |

화면의 일반직 예시는 두 부서·공통 예시 월 표로 제한한다. 기간의 전체 일반직 시간으로 수당 비율을 정하고, 해당 부서의 일반직 시간으로 일반직 기본급을 계산한다. 임의의 부서 추가·날짜별 표 버전 편집·다른 직책의 기본급 자동 합산은 아직 화면에 연결하지 않았다. 팀장 계산 예시는 직원 개인 실적을 자동 집계하지 않는다.

## 후속 구현

실제 업무 서버·인증·권한 작업은 기존 `SECURITY-ARCHITECTURE.md`에서 보류한 상태다. 이 변경은 보류를 해제하지 않는다.

1. 직원·팀·부서·직책·근로계약·그레이드 버전의 영속 데이터 모델과 서버 권한.
2. 최초 접수일·이전일·월말 팀 귀속 집계, 직원/팀장 확정 실적 스냅샷, 동일 접수 재귀속 중복 방지, A/S 검토·차감·복구 트랜잭션.
3. 실제 출결 승인·근무일정·유급시간 연결, 주·월 표 버전과 부서·직책 적용 기간 자동 분할.
4. 주휴 포함 시급 구성과 미사용 연차수당 기준 임금의 문서 검토. 임의 산식으로 대체하지 않는다. 연차 자동 발생·최저임금 법정 검증·주휴 계산은 아직 미구현.
5. 확정/취소/재확정, 공개/수정 중 명세서, 지급 완료, 퇴사자 별도 정산 실적 고정, 보정 감사 이력, 알림.
6. 근로계약 서명·직전 비밀번호 확인·버전 보관, 초기 계정 발급, 퇴사/재입사 접근 범위.
7. 관리자 급여대장·지급용 엑셀·PDF, 계좌 누락 처리 및 직원 화면 조회 권한.

퇴직급여 제도·연차사용촉진 운영 여부는 사용자 결정 대기이며 이번 계산 모듈에 임의 구현하지 않는다.

## 확인 방법

```sh
node --test payroll-engine.test.cjs
python3 -m http.server 8000 --bind 127.0.0.1
```

`http://127.0.0.1:8000/payroll.html`에서 예시를 검토한다. 파일을 직접 열면 브라우저 정책에 따라 운영 기준 JSON 로딩이 제한될 수 있다.

급여 계산 테스트 21개 통과. 전체 기존 테스트에서 지역/OCR 실패 2개가 있으며 변경 전 `17b4c3b`에서도 동일하게 재현했다:

- `intake-code.integration.test.cjs`: `충남북부` 명칭 기대값 불일치.
- `ocr-quantity-title.test.cjs`: `0`과 `불가` 기대값 불일치.

원래 지역·OCR 코드는 이번 급여 변경에서 수정하지 않았다.

화면 DOM 검증에서는 재계산, 현금 기지급 보호, 주 귀속 월, 공제·선지급 차감, 보정 재확인, 사용자 입력 HTML 이스케이프, 초기화, 관리직·팀장 예시 및 기준 검색을 확인했다. 브라우저 실행 파일을 받지 못해 실제 브라우저 렌더링·모바일 시각 검증은 아직 수행하지 못했다.

# 부서별 그레이드 노출과 전체 접수 관리

2026-10-03 한국 시간.

## 그레이드 노출

- 관리자 그레이드의 보험·화장품·건강보조식품 탭마다 일·주·월 체크박스와 노출 설정 저장 버튼을 제공한다. 저장/취소 확인 팝업을 거친다.
- `grade_visibility`에 부서별 3개 표시 값과 독립 revision, 변경자, 변경 시각을 저장한다. 기존 화면을 유지하기 위해 기본값은 모두 보임이다.
- 직원은 인증된 본인 부서의 설정만 받는다. 직원 홈 지급 기준, 그레이드 본문과 이력 상세, 상단 칩에 적용하며 기존 5초 요약 갱신에서 설정 변경도 반영한다.
- 지급 기준이 없는 화장품·건강보조식품의 기존 공개 제한은 유지한다. 노출 설정은 지급 중단 기능이 아니다. 급여 계산, 선지급, 지급 이력과 기준 revision을 바꾸지 않는다.
- 일부 항목만 공개한 경우 직원 합계와 월 비교표에서도 숨긴 항목을 표시하지 않는다. 급여 명세서의 실제 지급 항목은 유지한다.

## 전체 접수 관리

- 접수관리의 세 부서 탭 앞에 `전체 접수 관리` 링크를 추가한다. `/intake-live.php?role=admin`.
- 관리자 전용 `intake-live-api.php`에서 실제 `sales_records`만 SQL로 조회한다. 테스트·예시 자료는 포함하지 않는다.
- 전 부서의 가접수·정상접수·A/S를 최신 등록 ID 순으로 표시한다. 최초 콜 날짜를 과거로 입력해도 새 등록은 위에 나온다.
- 부서, 고객명 또는 전화번호, 접수 상태로 조회하며 한 번에 30행만 반환한다. 상담원은 직원 ID로 현재 계정 이름을 조회한다.
- 5초마다 자동 갱신한다. 숨겨진 탭, 검색 입력 중, 일시정지 상태에서는 주기 조회를 쉬며 요청 중복과 이전 검색 응답을 차단한다. 한글 조합 중에는 검색 결과를 바꾸지 않는다.
- 신규 건을 초록 배경과 새 접수 배지로 표시한다. 상세는 기존 접수 수정 팝업을 재사용하므로 목록 갱신이 입력 내용을 덮어쓰지 않는다.
- 새로운 검증은 배포 시 격리 SQLite에서 실행한다. 운영 DB에 검증 접수를 등록하지 않는다.

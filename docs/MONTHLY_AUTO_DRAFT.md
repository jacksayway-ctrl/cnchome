# 월 그레이드 자동 생성

첫 구간 시작 건수(기본 61)를 변경하면 이후 구간을 10건 간격으로 200건까지 자동 생성한다. 71로 변경하면 0~70, 71~80, 81~90, …, 191~200이 된다. 201건 이상은 마지막 금액을 이어 적용하여 기존 무상한 계산 구조를 유지한다.

금액 증가 규칙이 아직 별도로 지정되지 않았으므로 기존 구간의 시급·달성수당·건당 추가액을 순서대로 유지한다. 추가 구간은 마지막 기존 금액을 기준으로 ‘새 구간별 시급 증가’, ‘새 구간별 달성수당 증가’, ‘새 구간별 건당 추가액 증가’를 누적 적용한다. 세 값의 기본값은 0원이다. 임의의 인상률이나 시급을 만들지 않는다.

계산 예: 기존 마지막 시급 16,000원, 달성수당 300,000원, 건당 추가액 10,000원에 증가분 1,000 / 50,000 / 1,000을 설정하면 다음 신규 구간은 17,000 / 350,000 / 11,000원이 된다. 추가수당 시작 건수도 해당 구간 시작으로 맞춘다.

각 금액은 생성 표에서 개별 수정 가능하며 수정된 금액은 다음 구간 이동의 기준으로 보존한다. 201건 이상 행은 마지막 구간을 이어 사용하는 자동 표시다. 시작값과 증가액 변경은 편집 초안에만 적용되고 변경 내용 확인 후 저장해야 기준표에 반영된다. 저장된 과거 기록과 실제 급여 확정액은 변경하지 않는다.

검증: 주 20칸·금액 증가·시작값 이동, 월 200건까지 연속 구간·경계·금액 보존·추가 증가분·잘못된 입력 차단을 확인했다. 기존 참고용 급여 계산의 한계는 그대로 유지한다.

# 관리자 메뉴 구성

2026-09-25: 사이드바의 관리자 항목 19개를 상위 메뉴 6개로 통합했다. 상위 메뉴를 선택하면 첫 하위 페이지를 열고, 해당 업무의 하위 페이지 목록을 본문 위에 표시한다.

| 상위 메뉴 | 하위 페이지 |
| --- | --- |
| 관리자 홈 | 업무 현황 · 알림 · 운영 점검 |
| 영업 관리 | 접수 · 실적 · A/S |
| 인사·출결 | 직원 목록 · 직원 등록 · 출결 승인 · 연차·휴가 · 근로계약 |
| 그레이드 | 기준표 · 오늘 TM 일 그레이드 · 일 그레이드 지급 내역 |
| 급여·정산 | 급여·지급 · 계좌·지급 엑셀 · 정정·별도 정산 |
| 운영 관리 | 운영 설정 · 계정·권한 · 변경 이력 |

- 기존 페이지 해시 주소와 알림·업무 바로가기를 유지한다. 하위 페이지로 직접 진입해도 상위 메뉴와 현재 위치를 표시한다.
- 별도 급여 계산 검토 화면의 링크는 급여·정산의 하위 탐색 영역에 배치한다.
- 직원 화면에서는 관리자 하위 메뉴를 숨긴다. 직원 메뉴는 그대로 유지한다.
- 좁은 화면에서는 하위 메뉴를 가로로 스크롤할 수 있다. 키보드 포커스와 현재 페이지 표시를 제공한다.
- 메뉴 구성 변경이며 급여·그레이드 계산 규칙은 변경하지 않는다. TM 일 그레이드는 급여와 별도로 관리한다.

검증: 관리자 19개 경로의 상위·하위 활성 표시, 6개 메뉴 클릭 이동, 하위 페이지 이동, 직원 화면 전환, 기존 관리 업무 동작을 DOM 검사로 확인했다. 전체 자동 검사 86개 및 별도 급여 계산 화면 검사 통과. 실제 모바일 브라우저 시각 검증과는 구분한다.

직원 등록 전용 하위 페이지 추가 후 전체 관리자 경로는 20개다. 직원 목록에는 정보 보완 필요 항목과 상세·수정 버튼을 제공한다. 세부 항목은 STAFF_REGISTRATION.md 참고.
